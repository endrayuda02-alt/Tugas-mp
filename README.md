# Website Profil Siswa RPL

Website profil siswa jurusan Rekayasa Perangkat Lunak (RPL).

## File

- `index.html` — struktur website
- `style.css` — tampilan website
- `README.md` — informasi project

## Teknologi

- HTML5
- CSS3
- Bootstrap 5
- Bootstrap Icons
- Google Maps
- GitHub Pages

## Sebelum Dipublikasikan

Edit bagian berikut di `index.html`:

1. Nama siswa
2. Kelas
3. NIS
4. Alamat
5. Nama sekolah
6. Foto profil
7. Email
8. GitHub
9. Nomor telepon
10. Persentase keahlian

Untuk rute Google Maps, bagian `ALAMAT_RUMAH` sengaja dibuat placeholder.
Sebaiknya jangan memasukkan alamat rumah lengkap ke website publik. Jika tugas sekolah memang mewajibkannya, isi sesuai ketentuan guru sebelum pengumpulan.

## GitHub Pages

1. Buat repository bernama `profil-rpl`.
2. Upload `index.html`, `style.css`, dan `README.md`.
3. Buka `Settings > Pages`.
4. Pada Source pilih branch `main` dan folder `/ (root)`.
5. Klik `Save`.
6. Website akan tersedia melalui GitHub Pages setelah proses publikasi selesai.
